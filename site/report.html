まちがいの知らせ方

まちしるべのページで、まちがいや古い所を見つけたら、下の「知らせる」から送ってください。書く画面（Google フォーム）が開きます。アカウントも登録もいりません。作者が読んで、調べ直します。

  • 書いたことは、作者だけが読みます（公開されません）。
  • 自分の住所・電話番号・名前・家族のことは、書かないでください。返事はできません。
  • 急ぐこと（火事・けが・事件）は、ここではなく 119・110 へ。

知らせる

押すと書く画面が開きます。町のページから来たときは、町の名前と見ていたページが、はじめから入っています。

書き方

  1. 「知らせる」を押す

    書く画面が開きます。町の名前と見ていたページが入っていなければ、書いてください。

  2. 「どこがちがうか」を書く

    いまの書き方と、何がちがうかを短く。例：「○○地区の燃やせないごみの曜日が、火曜日になっているが、木曜日」

  3. 「正しいこと」を書く（分かれば）

    正しいと思うことと、どこで見たか（町のページ・お知らせの紙など）。分からなければ、書かなくてかまいません。

  4. 「送信」を押す

    それで届きます。直したことは、町のページの「このページで新しくなったこと」に出ます。

よくあること

日本語で書くのがむずかしい
ポルトガル語・スペイン語・英語など、どの言葉で書いてもかまいません。
返事が欲しい
この書く画面からは返事ができません。町のことの正しい答えは、町の役場に聞けます。役場の窓口の電話は、町のページの「困ったとき」にあります。
出典が分からない
「正しいこと」は分かる所だけでかまいません。「町のお知らせの紙で見た」なども助かります。
GitHub を使っている
GitHub の Issues でも受け付けています（書いたことは公開されます）。
