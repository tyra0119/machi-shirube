まちがいの知らせ方

まちしるべのページで、まちがいや古い所を見つけたら、GitHub（ギットハブ）の「Issues（イシュー）」という掲示板に書いて知らせてください。作者が読んで、調べ直します。

  • 書いたことは、だれでも見られます（インターネットに公開されます）。
  • 自分の住所・電話番号・名前・家族のことは、書かないでください。
  • 急ぐこと（火事・けが・事件）は、ここではなく 119・110 へ。

このページから知らせる

押すと GitHub の書く画面が開き、町の名前と見ていたページが入っています。下の 3〜5 の所だけ書き足してください。

書き方（はじめての人へ）

  1. GitHub のアカウントを用意する

    Issues に書くには、GitHub のアカウント（無料）が要ります。github.com/signup でメールアドレスを登録して作ります。表に出る名前は、本名でなくてかまいません。

  2. 知らせる画面を開く

    上の「このページから知らせる」のボタンか、新しい知らせを書く画面を開きます。ログインしていなければ、ログインの画面が先に出ます。

  3. 「Title」（題）を書く

    町の名前と、何がちがうかを短く。例：「黒潮町 ごみ：○○地区の燃やせないごみの曜日がちがう」

  4. 本文を書く

    下のひな形を「写す」で写し、「Add a description」の欄に貼りつけて、□ の所を書きます。

よくあること

    

      
英語の画面でむずかしい

      
題と本文は、日本語のほか、ポルトガル語・スペイン語など、どの言葉で書いてもかまいません。

      
アカウントを作りたくない

      
町のことの正しい答えは、町の役場にも聞けます。役場の窓口の電話は、町のページの「困ったとき」にあります。

      
出典が分からない

      
「どこで見たか」は分かる所だけでかまいません。「町のお知らせの紙で見た」なども助かります。
