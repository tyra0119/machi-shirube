# 使ったデータの出典

- 取得したファイルそのものはこのリポジトリに入れない（入れるのは加工した結果だけ）。
  加工のコードは期間中に書いたもの
- 「期間前」は、ハッカソンの開始（2026-11-02 12:00）より前に取得した公開データ。
  主催の決まりに従って明記する。置き場所は作者の PC の中だけで、このリポジトリには入れない
- 取得は名乗って、robots.txt と利用規約に従い、同じサイトへは1秒以上あける

## 期間中に使う見込み（使う前に利用条件を確かめる）

| データ | 出典 | 確かめること |
|---|---|---|
| 5mの標高（坂の計算） | 国土地理院 | 計算した結果を公開してよいか |
| 洪水・津波の浸水想定（地図のタイル） | ハザードマップポータル | 同上。タイルそのものは入れない |
| 地震の確率・表層地盤 | J-SHIS（防災科学技術研究所） | 数値をそのまま配らない決まり。町丁目ごとの結果を出せるか |
| 国勢調査の小地域（町丁目の境界と人口） | e-Stat | 出典の書き方 |
| 指定緊急避難場所 | 国土交通省・市町村 | 出典の書き方 |
| 町のオープンデータ（黒潮町など） | 各市町村 | 町ごとにライセンスを確かめる |
| 道・公園などの地図のデータ | OpenStreetMap | ODbL（取り出したデータを公開するときの扱い） |
