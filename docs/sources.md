# 使ったデータの出典

まちしるべで使う公開データの一覧。データを足すたびに書き足す。

- 取得したファイルそのものはこのリポジトリに入れない（入れるのは加工した結果だけ）。
  加工のコードは期間中に書いたもの
- 「期間前」は、ハッカソンの開始（2026-11-02 12:00）より前に取得した公開データ。
  主催の決まりに従って明記する。置き場所は作者の PC の中だけで、このリポジトリには入れない
- 取得は名乗って、robots.txt と利用規約に従い、同じサイトへは1秒以上あける

## 加工して入れたもの

| ファイル | 元 | 加工 |
|---|---|---|
| `site/data/japan.topo.json` | 国土数値情報 行政区域データ N03（2026年1月1日、国土交通省、CC BY 4.0） | 市区町村の番号ごとにまとめ、線を間引き、県の境目を作った（`npm run build:japan-map`） |
| `site/data/towns/{市区町村コード}.json` | 国勢調査 2020年 小地域の境界データ（人口・世帯つき。総務省統計局、e-Stat https://www.e-stat.go.jp/ 。**期間中の 2026-11-02 に取得**。利用規約は政府標準利用規約〈第2.0版〉準拠で CC BY 4.0 と互換） | 丁目を町・字にまとめ、人口と世帯を足し、線を間引いた（`npm run build:towns -- コード`）。いまは神戸市北区・朝霞市 |
| `site/data/stats.json` | 住民基本台帳 人口・世帯数と人口動態（総計）・年齢階級別人口・外国人住民（令和8年1月1日、総務省） | 市区町村ごとに割合を計算し、全国の市区町村 1,741 の中での位置を付けた（`npm run build:stats`。`docs/national-stats.md`） |

## 期間中に使う見込み（使う前に利用条件を確かめる）

| データ | 出典 | 確かめること |
|---|---|---|
| 5mの標高（坂の計算） | 国土地理院 | 計算した結果を公開してよいか |
| 洪水・津波の浸水想定（地図のタイル） | ハザードマップポータル | 同上。タイルそのものは入れない |
| 地震の確率・表層地盤 | J-SHIS（防災科学技術研究所） | 数値をそのまま配らない決まり。町丁目ごとの結果を出せるか |
| 国勢調査の小地域（町丁目の境界と人口） | e-Stat | 出典の書き方 |
| 指定緊急避難場所 | 国土交通省・市町村 | 出典の書き方 |
| 町のオープンデータ（黒潮町など） | 各市町村 | 町ごとにライセンスを確かめる |
| 道・公園などの地図のデータ | OpenStreetMap | ODbL（取り出したデータを公開するときの扱い） |
