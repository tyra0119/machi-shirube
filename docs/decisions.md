## 2026-11-02 町を選ぶ画面（日本地図）は使いやすさを先に詰める

- 作者「まずはここの UI が大事。ここが使いにくいと使う気になれなくなる」

  PC はマウスを乗せた町の名前を出す／拡大すると地図の上に名前（重なる名前は自動で間引く）／
  中の町から「← 戻る」で市区町村の地図へ（Esc でも）／政令市は区を選ぶカード

  スマホは地図が上、パネルが下
- 背景の地図（地理院の淡色地図）は拡大したときだけ出し、右上のボタンで消せる。県境は濃い点線
- 作者「カードに表示している項目は高い順、低い順などで検索できるといい。検索は朝霞市や、根岸台などの単位が選択できるといいな」→
  「数字で並べて探す」：範囲（全国の市区町村／県の中／市・区の中の町）・項目・高い順／低い順を選ぶと、
  上から50の一覧と地図の色分けが出る。一覧を押すと町のカードへ、「← 並べた一覧に戻る」で戻れる
  - 町・字の単位：人口・世帯・65歳以上・75歳以上・15歳未満・外国の住民・一人暮らし・65歳以上の一人暮らし・持ち家・共同住宅（国勢調査2020）
  - 市区町村の単位：上に加えて 75歳以上・0〜4歳・1世帯あたりの人数・国外からの転入・生まれた人と亡くなった人の差（住民基本台帳）、

## 2026-11-02 町のページの問題に気づけるようにする（点検とエラー調査）

- 作者「町のページを作成したとして、ページでエラーが発生している場合、まちしるべページで、それが分かるようにしたい。エラー調査のようなことができるといいな」
- 形（作るのは見張り〈11/7〉と一緒）：
  1. **点検**（Claude を使わない。毎日自動）：出典のリンク・データの古さ・ページの中身（空の欄・出典の無い数字）・ページを開いたときのエラー
     - 上津台で手作りしたときの経験から：404・410 はすぐ知らせる、5xx・つながらないは何回か続いてから、
       503 は「相手のメンテナンス中かも」と書く（「移った」と書くと要らない作業を生む）、403 はブラウザ以外を断るサイトで数えない、
       一覧の作りが変わって誤報が何十件も出たら1件ずつ並べず「見張りの読み方がずれたかも」の1件にまとめる
  2. **見え方**：日本地図の町に印、町のページの下に「このページの状態」、全部の町の「点検の一覧」
  3. **エラー調査**（手元の画面だけ）：問題の行の「調べる」で Claude が原因を探し（404 なら移った先を町のサイトの中で探す）、
     直し方を出典つきで「確かめる一覧」へ。直すかは作者が決める
- 先に入れたもの：いまの画面で、データが読み込めなかったら、パネルの上に何が読めなかったかを出し続ける（黙って空の画面にしない）

- **いまやること**（あとで作り直さないため）
  - 情報源カード・答え・点検の結果・確かめる一覧の1件ごとに「範囲」（段とコード。例 `town:281090990`・`muni:28109`・`japan`）を持たせる
  - 承認・修正・取り消しの記録の「誰が」は、名前ではなく利用者の番号で残す（いまは作者1人：`owner`）
  - 「この人はこの範囲でこれをしてよいか」は、プログラムの1か所（権限の判定）で決める。いまは「作者なら全部よい」だけ

  公開のサイトは見るだけなので、管理者を何人も置くにはログインと書きこみを受けるサーバーが要る（置き場所の候補は tyra.jp。
  そのとき鍵を使う場所・費用の上限を持つ人も決め直す）

  管理者は自分の範囲について「こういう情報も探して」（設計の7章）を頼める。権限の判定の「できること」は

  - 頼みの1件も「範囲」と「誰が」と日時を持つ。Claude が問いの形に直して物差しに足し、その問いだけ調べ直す

  - 決まりに合わない頼み（公式でない出典・個人の情報・噂）は理由を添えて断る。結果はいつもの承認の流れで、
    人が見るものはその範囲の管理者の確かめる一覧へ

## 2026-11-02 市を調べたあとに、その市の中の町を調べられるようにする

- 作者「朝霞市で調べた後、朝霞市根岸台で調べることができるようにする。その場合、朝霞市のページと朝霞市根岸台のページができる」
- 形：
  - **市・区を調べる** → 市・区のページができる（市・区で共通のもの：防災計画・ごみの分け方・広報紙・議会・市の話題など）
  - **その中の町を調べる** → 町のページができる（町ごとのもの：人口と年齢・浸水・揺れ・坂・避難場所・町の話題など）。
    市・区の調べた結果は使い回し、町では町ごとのものだけを調べる（費用と時間を減らす）
  - 市・区をまだ調べていない町を先に調べたときは、市・区で共通のものもそのときに集めて、市・区のページも一緒にできる
- 町村（黒潮町・大泉町など）は、そのまま1つの町なので、調べると町のページが1つできる
- URL：市・区のページ `/{県}/{市区町村コード}-{ローマ字}/`、町のページ `/{県}/{市区町村コード}-{ローマ字}/{町・字の4けた}-{ローマ字}/`
