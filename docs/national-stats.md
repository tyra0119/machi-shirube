# 全国の比べ（住民基本台帳）

町の「特色のカード」のもとになる、全国の市区町村の数字と、全国の中での位置。2026-11-02 に作った。

## 作り方

- `npm run build:stats`（`scripts/build-stats.mjs`）。入力は総務省の住民基本台帳の3つの表（令和8年1月1日。
  期間前に取得。`docs/sources.md`）。出力は `site/data/stats.json`
- 比べる相手は**市区町村 1,741**。表には県・郡の小計・東京都の「島しょ」の小計・政令市の区・北方領土の6村（人口 0）の行も
  あるので外す。政令市はまるごと1つで数え、区は数字だけ持たせて同じ 1,741 の並びに置いて位置を出す
- 地図の区域（N03）とは、市区町村コードの頭5けたでつなぐ。地図にあって数字が無いのは北方領土の6村と県の所属未定地の7つだけ
- 全国の中での位置は「自分より高い町の割合」（0% なら全国でいちばん高い）と、高いほうからの順位
- 特色のカードは、5つの数字（65歳以上・15歳未満・外国の住民の割合、1年の増減、引っ越しによる増減）を、
  **どの町でも同じ順で全部出す**。全国の上下 20% に入る数字には「目立つ」の印（3つまで）。
  どの町でも Claude を使わず、同じ決まりで出る
  - はじめは「真ん中から遠い順に3つ」にしていたが、町ごとに並びが変わって見比べにくかった
    （2026-11-02 作者「松本市、高山市のカードを見ると並びが違う。なぜ？」）ので、同じ順・同じ場所にした

## 境目（1,741 で計算）

| 数字 | 中央 | 高いほうから10% | 低いほうから10% |
|---|---|---|---|
| 65歳以上の割合 | 36.15% | 46.87% | 25.68% |
| 15歳未満の割合 | 10.02% | 13.05% | 6.95% |
| 外国の住民の割合 | 1.82% | 4.85% | 0.72% |
| 1年の増減 | −1.42% | +0.04% | −2.88% |
| 引っ越しによる増減 | −0.16% | +0.67% | −0.98% |

## 届きにくい人の候補（深掘りの型）を決まりで選ぶ（`site/types.js`）

全国の境目（上の表と、上から5%・20%）と、火山・豪雪・離島の印に当てはめて、町ごとに3つまで候補を出す。Claude は使わない。
本当に届きにくいのは誰かは、町を調べるときに Claude が公式の資料から見立て、人が確かめる（候補はその手がかり）。

| 型 | 届きにくい人 | 決まり |
|---|---|---|
| 母語で防災 | 外国から来て暮らす人 | 外国の住民が上から10%（4.85%）以上。上から5%（6.26%）以上はとくに強い |
| はじめての町 | 引っ越してきた人・若い家族 | 引っ越しによる増減か1年の増減が上から10%、かつ65歳以上が下から10% |
| 人が減る町の暮らし | 町に残る人・一人暮らしのお年寄り | 1年の増減が下から10%、かつ65歳以上が上から10% |
| 雪の暮らし | 雪下ろしや雪かきが難しいお年寄り | 特別豪雪地帯、または豪雪地帯で65歳以上が上から20% |
| 火山と暮らす | 火山のふもとに住む人・訪れる人 | 火山災害警戒地域 |
| 島の暮らし | 島に住む人 | 離島振興対策実施地域の島がある |
| 一人暮らしのお年寄り | 見守りや避難の声かけが届きにくい人 | 65歳以上の一人暮らしの世帯が上から10%（21.5%）以上 |

- まだ候補にできない型：わが家の避難（浸水・津波）・水と揺れ・坂の地図（浸水・揺れ・坂を計算してから）
- 確かめた例：大泉町・常総市 → 母語で防災、朝霞市 → はじめての町、津南町 → 雪の暮らし、夕張市 → 人が減る町の暮らし、
  洞爺湖町 → 火山と暮らす、八丈町 → 島の暮らし・火山と暮らす。黒潮町は浸水の計算のあとで「わが家の避難」が入る見込み

## 気づいたこと：大泉町は「全国一」ではなかった

- 大泉町の外国の住民の割合 21.84% は、1,741 のうち **6番目**。上の5つは北海道赤井川村 36.75%・占冠村 35.52%・
  倶知安町 24.6%・長野県白馬村 22.74%・北海道留寿都村 21.87%（どれもスキー場のある町村。1月1日の数字）
- 大泉町が1番になる言い方：「人口2万人以上の市区町村で全国一」（2番は新宿区 14.46%、3番は蕨市 14.16%）
- **決めた（2026-11-02 作者）**：画面とナレーションでは「**人口2万人以上の市区町村で全国一**」と言う
  （人口2万人以上は 1,741 のうち 909）。特色のカードは「全国で6番目に高い」に、この言い方を添える
- カードの決まり：人口2万人以上の市区町村の中で3番目までに入り、全国の順位より上になる数字には、
  どの町でも「人口2万人以上の市区町村では〜」を添える（大泉町のためだけの決まりにしない）
