## B. 町のサイトを Anthropic 側から取る（2026-11-02）

- `npm run try:fetch`：PC 側（名乗って robots.txt → 1秒あけてトップ）と、Claude のページを取る道具（web_fetch）の両方で黒潮町のトップを取る
- PC 側：robots.txt は `/login/` だけ禁止。トップは 200、UTF-8
- Anthropic 側：**取れた**（海外からだと断られる、ということは黒潮町では無かった）。
  Claude はトップから「防災コーナー」「11月15日の総合防災訓練」などのリンクを拾えた
- つまずいたこと：1回目は「取得回数の上限に達した」で答えられなかった（$0.09）。
  web_fetch は中で小さなプログラムを動かして中身を絞り込み、そのときもう一度取りにいくので、
  取得の回数（max_uses）を 1 にすると足りない → **max_uses は 3 以上にする**。2回目は答えた（$0.10）
- 同じ URL は Anthropic 側で取ったものが使い回される（取得の時刻が2回とも同じだった）。
  「確かめた日」には、この取得の時刻を使う
- ほかの町では断られるかもしれない。断られたら PC 側で取って中身を Claude に渡す道は、いつでも使える

## C. 防災計画の PDF を引用つきで読む（2026-11-02）

- 黒潮町地域防災計画（令和8年3月、町の「黒潮町の計画」のページから。24MB・298ページ）。PDF は `local/pdf/`（公開しない）
- まるごと渡すのはやめた：1回に送れる大きさ（32MB）を、送るときの形にすると超える。
  中身も 300ページぶんで、1回 $3 以上かかる見込み
- 代わりに **目次から当たりをつけて、関係するページだけを切り出す**（`pdfjs-dist` で文字を取り出し、`pdf-lib` で切り出す）
  - 目次で「第5編 第1章 第2節 津波から避難する対策」が 276 ページ。PDF では 282 枚目（表紙などで 6 ずれる）
  - 282〜286 枚目の5ページを `npm run try:pdf` で読ませた
- 結果：要点を3つ答え、**どれにも元の PDF の何枚目かの引用が付いた**（282・283・284・285 枚目）。入力 12,417・出力 461 トークン、**$0.059**
- 分かったこと
  - PDF の引用はページの単位（「何ページのどの文」までは出ない）。出典には「計画の 277 ページ」のように、計画に印刷されたページ番号を出す（PDF の枚数から 6 を引く。ずれは資料ごとに目次と照らして決める）
  - この PDF は中の作りに少し壊れた所があり、切り出しのときに警告が出るが、切り出しと読み取りはできた

## D. 全国の市区町村の形（2026-11-02）

- 元：国土数値情報 行政区域データ N03（2026年1月1日）。12万5千の形、258MB
- `npm run build:japan-map`（mapshaper）で、市区町村の番号ごとにまとめ、線を 1.5% に間引き、
  県の境目を別にまとめて `site/data/japan.topo.json` に書き出す。18秒
- できたもの：**2.4MB（圧縮して配ると 0.7MB）**。区域 1,905・県 47
  - 内訳：市区町村 1,741 のうち政令市 20 は区（171）に分けて 1,892。北方領土の6村。県ごとの所属未定地 7（番号は「12000」のような県の番号）
  - 深い町の番号を確かめた：黒潮町 39428・大泉町 10524・朝霞市 11227。神戸市北区 28109
- ブラウザ（canvas に全部描く簡単な試し）：読み込み 約0.06秒、描くのに 約0.5秒
- 分かったこと
  - 沖ノ鳥島はとても小さく、間引くと消える（いちばん南が北緯24度）。全国の地図には差し支えない
  - 間引きで線どうしが交わる所が 50 か所残った。全国を見る大きさでは見えない
  - 全部を毎回描き直すと 0.5秒かかるので、動かしたり拡大したりする画面では、描き方を工夫する
    （地図の部品を使う。決めるのは日本地図の画面を作るとき）
- → 日本地図の最初の画面（`site/`、`npm run serve` で http://127.0.0.1:8080/）は **MapLibre GL JS**（BSD-3）で描くことにした。
  動かすたびに全部を描き直さないので軽い。操作は Google マップと同じ形（ドラッグで移動・右ドラッグで回転と傾き・
  ホイールで拡大縮小・2本指でひねる／広げる／傾ける）が最初から入っている。背景の地図の画像は使わない
  - ボタンは右下に縦に（上から 方角・現在地・＋・−）。方角は北を上に・真上からに戻す。現在地は取れないときに一言出す
  - 北方領土と所属未定地は灰色（押すと「国の統計がありません」）。見ている場所は URL の `#z=拡大/緯度/経度` に入る
  - 夜の画面（ダークモード）の色も作った。スマホ実機ではまだ確かめていない
