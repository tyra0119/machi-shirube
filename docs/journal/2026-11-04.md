## Claude Code をどう使ったか

- ブラウザ（MCP）で、町のページを住む人の立場で開き、スマホの幅・ほかの言葉で押して確かめた。気になる所を表にして、作者が決めたものだけを直す、をくり返した
- 実機：USB でつないだ Android のスマホで、adb で公開のサイトの画面を録った。押す位置は画面の座標から決めた
- 動画の確かめ：書き出した動画をブラウザで開き、時刻を指定して止めた。何枚ものコマを1枚の絵に並べて（キャンバスに描いて）、場面の切れ目・字の重なり・黒いコマを1コマ単位で見つけた
- Premiere のためのファイル：録画の長さとコマの速さを、mp4 のファイルの中の表から Node で読み、場面の時間に合わせて切る所と速さを計算して XML に書いた。字幕の絵は Windows の描く仕組み（PowerShell の System.Drawing）で作った。ボタンの位置は、書き出した動画のコマに方眼を重ねて測った
- 作品の中の Claude：阿賀町で、調べる（Sonnet）→ 確かめ役・採点（Haiku）→ 見立て → 調べ終わりの提案（Managed Agents。採点役が1回目で合格）まで通した
- 長い仕事は裏で：ごみの辞書の訳を裏で動かした。止めたつもりでも、中の node の仕組みが動き続けてファイルを上書きした（費用は2回分の約 $8.3）。止めるときは中の仕組みまで止まったかを確かめる
- 別のセッション：動画の台本の時間の変更を、台本を受け持つセッションに知らせた
