- 病院の URL・介護の電話・避難場所の座標・クイズ・お知らせなど、全国のデータを Node で一度に調べた
- 正規表現の書きかえは、前のコード（git show）と新しいコードを同じ文に当てて、結果が1つもちがわないことを確かめた
- 時刻：シェルの TZ の指定が効かず、日本時間を読みまちがえた（午後を朝4時と書いた）。時刻は Node で UTC から足して確かめる
