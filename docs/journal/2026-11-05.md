### Claude Code をどう使ったか

- ブラウザ（MCP）の中に町のページを iframe でいくつも開き、エラー・はみ出し・日本語の残り・字の明るさの差・404 を機械で数えた。画面が隠れていると地図が描かれないので、それを逆に「地図が届かないとき」の確かめに使った
- 気象庁の 58 の予報区のファイルを 1 秒ずつあけて取り、全国 1,756 の町の区切りが本当にあるかを照らした（警報の 8 市・予報の 2 地方が見つかった）
- 病院の URL・介護の電話・避難場所の座標・クイズ・お知らせなど、全国のデータを Node で一度に調べた
- 正規表現の書きかえは、前のコード（git show）と新しいコードを同じ文に当てて、結果が1つもちがわないことを確かめた
- 時刻：シェルの TZ の指定が効かず、日本時間を読みまちがえた（午後を朝4時と書いた）。時刻は Node で UTC から足して確かめる
