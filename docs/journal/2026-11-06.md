### Claude Code をどう使ったか

- 見た目の案は、サイトを変える前に、会話の中に動く見本（絵と並べ方の2案）を描いて選んでもらった
- 実機の確かめは、つないだ Android に adb でページを開き、画面を撮って縮めて見た（手元のサーバーは adb reverse でつないだ）
- 新しい欄の見出しが、ほかの言葉で日本語のまま出ていたのを画面の点検で見つけ、訳す見出し語に town.html の見出しが自動で入るように直した（同じまちがいが戻らないように）
- OpenStreetMap の取り出しは、overpass-api.de の robots.txt が /api/ を断っていたので、公開の窓口 overpass.kumi.systems を使った。まとめて頼むと 504 で断られたので、種類ごとに分け、間をあけて頼み直す形にした
- 動画の確かめは、YouTube の自動の字幕を 0.08 秒ごとに読み、言葉が出る時刻を集めた。その時刻で字幕のファイルの時刻を決めた
