## Claude Code をどう使ったか

- **計画を読んで、危ない所を先に挙げる**：設計・物差し・台本を読み、決まりに触れそうな所（計画の文を写すおそれ・鍵の置き場所の書き方のゆれ）を挙げてから作り始めた
- **Claude API のスキル**（claude-api）で、Managed Agents・web_fetch・PDF の引用の正しい呼び方を確かめてから書いた（覚えている形で書かない）
- **組み込みのブラウザ**で、作った画面を毎回開いて確かめた（押す・探す・幅を変える・夜の画面・PC とスマホの幅）。数字は画面の中の JavaScript で照らした
- **時間のかかる取得は裏で動かし**、そのあいだに画面を作った（国勢調査 47 都道府県の取得）。同じサイトに2つ同時に取りにいかないよう、順番に動かした
- **公開データの確かめ**：利用規約（e-Stat・地理院タイル）とrobots.txt を読んでから取った。取るときは名乗り、1秒以上あけた
- **コミットの前の点検**：毎回、鍵の文字列・`local/`・PC のパスが入っていないかを確かめた
