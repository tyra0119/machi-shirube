## Claude Code をどう使ったか

- 作品の中の Claude：調べる（Sonnet・web_search・web_fetch・公式サイトだけ）、確かめ役（Haiku）、提案とスキル、頼みを問いに直す、訳と訳し戻し、ごみの表の列の見分け
- 機械でできることは機械で：数の数え直し・元の文の照らし合わせ・点数・見張り・天気や病院や避難場所の計算（見る人のブラウザで）
- 組み込みのブラウザで、作った画面を毎回開いて確かめた（PC とスマホの幅・4つの言葉・公開のサイト）
- **フック**：コミットの前に、鍵の文字列・local/ のもの・PC の道筋が入っていないかを機械が確かめて止める（`.claude/settings.json`）。これまで毎回手で確かめていたのを、忘れようのない形にした。わざと鍵らしい文字を入れて止まるのを確かめた
- **長い仕事は裏で**：ごみを出す日の読み取り（1町数分）を裏で動かし、そのあいだに別の仕事をした。終わると知らせが来る
- 準備の文書の突き合わせは、2つの担当に分けて読ませた。kozdai の経験は、kozdai のセッションに文書にしてもらい、知識として読んで自分の言葉で作り直した
