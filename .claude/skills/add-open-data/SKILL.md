# 外部のデータを重ねる手順（まちしるべ）

町の公式の答えは土台。そのうえに、国や公の機関のデータを重ねて、市や区のページを見ても分からないことを出す
（例：250m 四方の人口 × 浸水の想定 → 浸水が想定される所に住む人）。

## 1. 使ってよいかを先に確かめる

- 利用条件のページを読む。よくある形：
  - 公共データ利用規約（第1.0版）・政府標準利用規約（第2.0版）・CC BY 4.0 → 出典と「加工して作成」を書けば使える
  - 「加工した成果は配ってよいが、そのままの複製は配らない」（例：J-SHIS）→ 足し上げた数だけを入れる
  - 「転載・再配布は前もって連絡」（例：農林水産政策研究所の表）→ 表まるごとは入れず、要る町の行だけを出典つきで引用
  - ライセンスの名前が無い → 作者が使ってよいとしたサイト（情報源カード）の決まりの中か、作者に聞く
- 有志が作るデータ（OpenStreetMap など）は、地方の載り漏れで数が大きくずれることがある。試しに1町で数を見て、実際とかけ離れていたら使わない

## 2. 行儀よく取る

- 名乗る（User-Agent：`machi-shirube/0.1 (+https://github.com/tyra0119/machi-shirube)`）・robots.txt を見る・同じサイトには 1 秒以上あける・同じサイトを同時に取らない
- 取ったものそのもの（表・地図の絵・API の返事）は `local/cache/` にだけ置く。`scripts/build-flood-pop.mjs` の `cached()` を使うと、取り直さずに済む
- 見る人のブラウザがその場で読むもの（雨雲・キキクルなど）は、CORS が通るかを確かめる

## 3. 重ねて数える

- 人に重ねるときは、町・字の人口を面積で割り振らず、250m 四方の人口（国勢調査 2020年 地域メッシュ T001142）を使う（`townMeshes()`）
- 数は公表の値と照らす（合計の人口・全国の割合など）。合わなければ直す
- 人は四角の中に均等に住むとみなすなど、仮定のある数は「めやす」と書き、仮定もページに書く。全国と比べるときは、全国の真ん中の値を添える（上か下の10番目までは「○番目」、ほかは「高いほう」「低いほう」。「上から ○%」は使わない）

## 4. 出す・記録する

- `site/data/<名前>/<コード>.json` に、足し上げた数・注意書き（note）・出典（sources）を入れる。ページの部品は `site/town.js` に、ほかの言葉の見出しは辞書（`site/data/i18n/keys-page.json` → `npm run i18n`）に
- `docs/sources.md` に1行（何を・どこから・いつ取ったか・利用条件・どう加工したか）、`docs/decisions.md` に決めたこととつまずき
- 全国の町の分を作れるもの（交通事故・これからの人口）は全国で作り、日本地図の「数字で並べて探す」にも足す（`npm run build:summary`）
