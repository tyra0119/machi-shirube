# 町を深く調べる手順（まちしるべ）

1つの市区町村（市区町村コード 5 桁）について、町のページに出すものを順に作る。どれも `site/data/` に書き出し、
人の確かめが要るものは承認の台帳（`local/ledger/`）の確かめる一覧に入る。

## 先に確かめること

- 費用：`src/cost.mjs` の上限（1日・合計・1回の調べ）。いま使った額は `local/costs.jsonl` の合計
- 鍵は `.env` だけ（`npm run` の動かし方が `--env-file=.env` で読む）。鍵を表示しない
- 町の公式サイトを初めて使うときは、作者が確かめる一覧で「使ってよいサイト」にするまで、答えはページに出ない

## 順番

1. **国のデータを重ねる（Claude は使わない・無料。1町で数分〜10分）**
   `node scripts/overlays.mjs <コード>` … 浸水・土砂（250m 四方の人口 × ハザードマップ）、地震の揺れの確率（J-SHIS）、交通事故、買い物（農林水産政策研究所）。
   地図の絵や J-SHIS は 1 秒おきに取るので、裏で動かす
2. **物差しの問いを調べる（Sonnet。1町で $3〜4 まで）**
   `npm run research -- <コード> --all` … 答えごとに採点役（Haiku）が 0〜3 点を付け、1 点以下なら指摘を添えて1回探し直し、良いほうを残す。
   すでにある答えの採点し直し：`npm run research -- <コード> --regrade`
3. **届きにくい人の見立て（1町 約1セント）**：`npm run mitate -- <コード>` … 1 と 2 のあとに。理由の数が渡した数にあるかを PC が照らす
   - 町・字ごとのひとこと（3町で約 $0.1）：`npm run hitokoto -- <コード>`
   - 数から、できることへ（1町 約2セント）：`npm run dekiru -- <コード>` … 2 の答えを作者が確かめたあとに（確かめ済みの答えだけを引く）。数と引用を PC が照らし、確かめる一覧に1件入る。作者が OK するまで町のページに出ない
4. **町ごとに資料を選んでから動かすもの**
   - 防災計画の町・字ごとの抜き出し：`scripts/plan-excerpts.mjs` の `PLANS` に計画の PDF を足してから `npm run plan-excerpts -- <コード>`（1町 約$1）
   - ごみを出す日：`npm run gomi-days -- <コード>`（1町 約$0.5）
   - バスの便利さ：`scripts/build-bus.mjs` の `FEEDS` に GTFS を足してから `npm run build:bus -- <コード>`（GTFS データリポジトリ https://gtfs-data.jp/ で探す。ライセンスを確かめる）
5. **外国の住民が多い町は訳す**：`npm run translate -- <コード> pt,es,en,easy,id,ne,vi` と `npm run i18n -- <言葉>`。訳し戻してずれたものは確かめる一覧へ。AI が作った文（見立て・ひとこと・数から、できることへ）は `npm run translate-ai -- <コード> <言葉>`（作り直したら訳し直す）
6. **公開のファイルを書き出す**：交通事故・これからの人口を作り直したら `npm run build:summary`。どの町でも最後に `npm run build:muni`（町ごとの小さなファイルの「ある物の一覧」と訳のある言葉を合わせる。浅い町のファイルの一覧のままだと、町のページが新しいデータを読みに行かないことがある）

## 確かめてからコミット

- **`npm run check`**（費用 0・数十秒）で、前に起きた不具合が戻っていないか・作り直し忘れ（build:muni・split-tr・i18n）が無いかを調べる。× が 0 になるまで直す
- 手元のサーバー（`npm run serve:research`）で **`http://127.0.0.1:8080/check`** を開いて「点検する」を押す。調べた町を、点検のページ（`scripts/check-page.html` の PAGES）に1行足してから押す（エラー・止まり・幅 320px のはみ出し・字の読みやすさ・ほかの言葉の日本語の残り・無いファイル）
- 新しい種類の不具合を見つけて直したら、同じ種類がほかに無いかを全部のデータとコードで探し、`scripts/check.mjs` の CASES（関数の例）か、点検のページの PAGES（画面）に1行足す。次の町で同じ不具合をふまないように
- 町のページ（`town.html?muni=<コード>`）を開き、いちばん上の見立て・防災・地図・交通のページを、パソコンとスマホの幅で見る
- 数は公表の値と照らす（250m 四方の人口の合計 ≒ 町の人口など）。合わないときは原因を直してから
- 決めたことは `docs/decisions.md`、使ったデータは `docs/sources.md` に書く
- コミットの前のフック（`scripts/hooks/check-commit.mjs`）が、鍵・`local/` のもの・PC の道筋を止める。止まったら取り除く
