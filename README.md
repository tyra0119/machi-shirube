# まちしるべ

町を選ぶと、その町で暮らしの情報が届きにくい人を Claude が見つけ、
その人に届くページを、出典つきで作る仕組み。

- Built with Claude: Japan 2026 の作品（テーマ2「本来、誰にでも届くべきものを」）
- 作者: tyra
- 公開サイト: https://tyra0119.github.io/machi-shirube/ （見るだけ。調べる・確かめるは作者の手元の画面だけ）
- 使う人：その町に住む人みんな。毎日開く理由（今日の天気・警報・今日やっている病院・ごみの日）があるから、いざという時の備えにも届く

## 誰の、どんな壁を

町ごとに、届きにくい人はちがう。国の数字で先に見つけ、その人の壁を越える情報を出す。

| 町 | 届きにくい人と壁 | まちしるべが出すもの |
|---|---|---|
| 高知県 黒潮町 | 65歳以上が 47.17%（全国の市区町村の上から 9.6%）。津波で浸かる想定の所に約 5,340 人（町の 52.3%、めやす）。坂の上の避難場所まで逃げにくい | わが家の避難（浸水の深さ・海抜・坂を考えた歩く時間）、防災計画の町・字ごとの抜き出し、昔の津波を伝える碑と町・字ごとのひとこと |
| 群馬県 大泉町 | 外国の住民が 21.84%（人口2万人以上の市区町村で全国一）。町の防災マップは日本語・英語・ポルトガル語だけで、スペイン語・インドネシア語・ネパール語・ベトナム語・やさしい日本語の版がない | 町のページ全体を 7 つの言葉で（訳は別の Claude が日本語に訳し戻して照らす）。洪水で浸かる想定の所に住む人 約 18,730 人（44.4%、めやす） |
| 埼玉県 朝霞市 | 若い家族が多い市（65歳以上が 19.77%、全国の市区町村の低いほうから 1.3%）。市は広いので、中の町（根岸台など）まで下りて見る | 町・字ごとの数字、ごみを出す日（45 地区）、手続きの窓口 |

## 住む人の画面でできること

- 今日：天気・洗濯と服装・警報と地震・今日やっている病院（全国）・この町で届きにくい人の見立て・数から、できることへ・このページで新しくなったこと
- 防災：浸水・土砂の想定の区域に住む人、大きな地震の揺れの確率、坂、わが家の避難、防災計画の町・字に関係する所、昔の災害を伝える碑
- 重ねて見る地図：気をつけたいことの重なり・避難場所・病院・雨雲・キキクル・浸水・土砂・事故・バス停・碑を選んで重ねる
- 交通と道の安全（バスの平日の時刻表・路線の地図）・お年寄り・子育て・手続き・ごみ（地区ごとの出す日）・町を知る（町のクイズ・気候・これからの人口・町ゆかりの人と名所）
- わが家の避難から、Google マップで歩く道を見る（押したときだけ、選んだ場所と避難場所を渡す）。防災散歩（上りの少ない避難場所まで、ふだんの散歩で歩いてみる）
- 長いページは、各欄を「見出し＋大事な数の1行」にたたみ、上に目次。いちばん下に「このサイトについて」と、まちがいの知らせ方のページ
- 言葉：日本語・ポルトガル語・スペイン語・英語・やさしい日本語・インドネシア語・ネパール語・ベトナム語

## しくみ

```
国の統計で全国 1,741 市区町村を比べる（Claude なし）
  → 町を選んで「調べ始める」（作者の手元の画面）
  → Claude が町の公式サイト・防災計画を探して読み、物差しの問いに出典つきで答える
  → 確かめ役の Claude が資料と照らし、採点役の Claude が 0〜3 点を付け、足りなければ1回探し直す
  → 国や公の機関のデータを重ねる（浸水 × 250m 四方の人口・揺れ・坂・事故・買い物・バス・気候・碑）
  → Claude が「届きにくい人」を見立て、その人の支援の問いを結ぶ。町・字ごとのひとこと、数から、できることへ
  → 権利・食い違い・古いデータ・避難にひびくものだけ人が確かめる（確かめる一覧）
  → 公開のページは静的なファイルだけで動く（Claude も鍵も使わない）
```

AI が作った文は、どれも「渡した数と、確かめ済みの答えだけ」を使わせ、文の中の数と引用を PC で照らしてから出す。

## Claude の使い分け

作品の中（調べる・確かめる。`scripts/`）

| 役 | モデル | 使い方 |
|---|---|---|
| 調べる | Sonnet 5.5 | web_search・web_fetch で町の公式サイトだけを読む（`scripts/research.mjs`） |
| 防災計画の抜き出し | Sonnet 5.5 | PDF のページを文書として渡し、citations で引用つきに（`scripts/plan-excerpts.mjs`） |
| PDF を絵として読む | Opus 5.5 | 文字の取れない防災マップなど（`scripts/try-pdf.mjs`） |
| 確かめ役・採点役・訳し戻し | Haiku 5.5 | 答えと資料を照らす、0〜3 点、訳を日本語に戻して意味を比べる |
| 見立て・ひとこと・数から、できることへ・クイズ | Sonnet 5.5 | 渡した数だけで書かせ、数と引用を PC で照らす（`scripts/mitate.mjs` ほか） |
| 調べ終わりの提案（物差しに無い問い・調べ方のスキル） | Managed Agents（Sonnet 5.5） | outcomes：物差し（ルーブリック）に合うまで別の採点役がやり直させる（`scripts/managed-propose.mjs`） |

作る側（Claude Code。この作品はすべて Claude Code で作った）

- スキル：町を深く調べる手順（`.claude/skills/town-deepen`）、外部のデータを重ねる手順（`.claude/skills/add-open-data`）
- フック：コミットの前に、鍵の文字列・`local/` のもの・PC の道筋が入っていないかを止める（`.claude/settings.json` → `scripts/hooks/check-commit.mjs`）
- サブエージェント：準備の決めごととの突き合わせ、抜けの洗い出し、デモの台本と作品の照らし合わせ（数・言葉・場面を1つずつ。食い違い22件）
- ブラウザ（MCP）：町のページ・調べる画面・スマホの幅を実際に開いて確かめる
- 実機：USB でつないだ Android のスマホで手元のサーバーを開き、画面を撮って確かめる（地図のボタンと目次のボタンの重なりなど）
- 別のセッション：台本と概要の文書（作品の外）を受け持つセッションに、数の直しを知らせる

## 安心して使えるための決まり

- 出典は公式（と国・公の機関）だけ。どの数字にも出典と時点を添える。想定・確率は「めやす」と書き、断定しない。町に順位は付けない（「上から ○%」と言う）
- 医療の助言はしない。転載を禁じているサイトは、事実とリンクだけにする
- 取得は robots.txt と利用規約に従い、名乗って、同じサイトへは1秒以上あける。取ったものそのものは `local/` にだけ置く
- 人が確かめたもの・自動で出したものの記録（承認の台帳）を残し、サイトごとに取り消せる
- 費用の上限：1回の調べ $4・1日 $80・合計 $550（`src/cost.mjs`）
- 住む人のページには、作る側の中身（Claude への問い・費用・台帳の番号）を出さない。AI が作ったものは「AI」と書く

## 動かし方（手元）

```bash
npm install
npm run serve            # 見るだけ。http://127.0.0.1:8080/ （手元だけで待ち受ける）
npm run serve:research   # 調べる・確かめる画面も使う（.env の ANTHROPIC_API_KEY を読む）
```

API の鍵は、このフォルダの `.env`（`.gitignore` 済み）にだけ置く。公開のサイト（GitHub Pages）は `site/` をそのまま配る（`.github/workflows/pages.yml`）。

デモ動画を録るためのページ（ふだんの画面には出ない）：
- `flyover.html`：これからの姿の演出（イメージ）。夜の日本の上を沖縄から札幌へ立体で飛び、町が灯っていく。画面にいつも「演出（イメージ）」と出す。地形は地理院の標高タイル、町の形は国土数値情報 N03
- `index.html?wave`：本物の灯りの波。全国 1,741 の市区町村（どれも国の統計で特色のカードがある）を九州から北へ順に灯し、最後に Claude が深く調べた町が浮かび上がる

町を1つ深く調べる順番は `.claude/skills/town-deepen/SKILL.md` に書いている（国のデータを重ねる → 調べる → 見立て → ひとこと → 数から、できることへ → 訳）。

## データの作り方

期間前に取った公開データ（`docs/sources.md`）を `data/raw/` に置いてから：

```bash
npm run build:japan-map  # 市区町村の形（N03）→ site/data/japan.topo.json ほか
npm run build:census     # 国勢調査2020 の世帯と住まい（e-Stat から47都道府県ぶん取る）→ data/census-munis.json
npm run build:stats      # 住民基本台帳と国勢調査から、全国の市区町村 1,741 と比べた数字 → site/data/stats.json
npm run build:flags      # 南海トラフの津波・火山・豪雪・離島の印 → site/data/flags.json
npm run build:towns -- all  # 全国の町・字の形と数字（e-Stat から県ごとに取る）→ site/data/towns/
npm run build:lore       # 昔の災害を伝える碑（国土地理院）→ site/data/lore/
```

町ごとに国のデータを重ねる計算は `node scripts/overlays.mjs <市区町村コード>`（町を調べるときにも自動で動く）。
e-Stat などから取るときは名乗り、1秒以上あけ、手元にあるものは取り直さない。
