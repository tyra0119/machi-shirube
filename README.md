# まちしるべ

町を選ぶと、その町で暮らしの情報が届きにくい人を Claude が見つけ、
その人に届くページを、出典つきで作る仕組み。

- Built with Claude: Japan 2026 の作品（テーマ2「本来、誰にでも届くべきものを」）
- 作者: tyra
- 公開サイト: https://tyra0119.github.io/machi-shirube/ （見るだけ。調べる・確かめるは作者の手元の画面だけ）
- 審査の方へ：町を調べる体験（本物の調べの記録の再生と、人が確かめる所を試せるページ）: https://tyra0119.github.io/machi-shirube/try.html
- 町を調べてページを作る（Claude を動かす）のは、このリポジトリを手元で `npm run serve:research` で動かしたときだけ。公開サイトは、調べ終わった 5 つの町のページと全国の地図を見るためのもので、新しい町を調べることはできない（公開サイトには鍵を置かないため）
- 使う人：その町に住む人みんな。毎日開く理由（今日の天気・警報・今日やっている病院・ごみの日）があるから、いざという時の備えにも届く
- 離れて暮らす家族も：親が一人で住む町、進学や就職で家を出た子どもの町など、家族の町の「今日」（天気・警報・今日やっている病院）を、自分の町と並べて見られる（トップのいちばん上に「前に見た町」）

## 住む人の画面でできること

- 今日：天気・洗濯と服装・警報と地震・今日やっている病院（全国）・この町の、こんな人へ（届きにくい人の見立てと町の支援）・いま、できること・町からのお知らせ（町の公式サイトの新着の見出しと、広報紙の最新号）・このページで新しくなったこと・今日の一問（町のクイズを日替わりで）
- 毎日開いてもらう工夫：今日のページのいちばん上に「きょうのひとこと」（ごみ・天気と傘・警報・町の明るい話題・今日は何の日〈町の誕生日・もうすぐの催し〉。ひと目で終わる短い行）。夕方（町の時刻で 18 時）からは「明日の準備」（明日の天気・洗濯・服装・ごみ・やっている病院を先に）。前に見てから新しくなったお知らせ・広報紙・新しくなったことに「新しい」の印（見たものは端末の中だけに覚える）
- 防災：浸水・土砂の想定の区域に住む人、大きな地震の揺れの確率、坂、わが家の避難（避難場所の位置のデータが無い阿賀町は、地域防災計画の資料の表から、行政区ごとの避難施設の一覧）、防災計画の町・字に関係する所、昔の災害を伝える碑
- 重ねて見る地図：気をつけたいことの重なり・避難場所・病院・雨雲・キキクル・浸水・土砂・事故・バス停・碑を選んで重ねる
- 交通と道の安全（バスの平日の時刻表・路線の地図）・お年寄り・子育て・手続き・ごみ（地区ごとの出す日）・町を知る（どんな町？〈深く調べた町は確かめた答えから AI がまとめた紹介、どの町でも国の数字から決まりでまとめた「数で見る○○」〉・町のクイズ・気候・これからの人口・町ゆかりの人と名所）
- わが家の避難から、Google マップで歩く道を見る（押したときだけ、選んだ場所と避難場所を渡す）。防災散歩（上りの少ない避難場所まで、ふだんの散歩で歩いてみる）
- 印刷：冷蔵庫に貼れる「くらしのメモ」（memo.html）と、紙の回覧板にはさむお知らせ（kairan.html。このサイトの説明・町のページの QR コード・見た家の印の欄・切り取れる QR の札）
- 選んだこと（ごみの地区・わが家の避難の町・字・言葉・文字の大きさ・前に見た町）は端末に覚える。字が小さいときは「文字を大きく」（ページの字を 1.2 倍に）。ホーム画面に置ける（アイコンを押すと、前に見た町から開ける）。電話番号は押してかけられる。答えの多いページは「見出し＋要点（＋電話）」にたたむ
- ページの行き来：スマホでは画面の下のメニュー（今日・地図・防災・ごみ・ほか）、パソコンでは上のメニュー。「ほか」と「すべてのページ」の一覧には、いちばん上に「このページの中」の欄の一覧も出す
- 長いページは、各欄を「見出し＋大事な数の1行」にたたむ。いちばん下に「このサイトについて」と、まちがいの知らせ方のページ（Google フォーム。アカウントも登録もいらない）
- 町の名前は、ひらがな・カタカナ・ローマ字でも探せる。町のページは右上の印のボタンで人に送れる。ページの中の地図は、スマホでは2本指で動かす（指1本はページを動かす）
- 言葉（町の名前の下の地球の印のボタンで選ぶ。横に、その町に多い国籍の言葉を2つ）：日本語・ポルトガル語・スペイン語・英語・やさしい日本語・インドネシア語・ネパール語・ベトナム語・フィリピノ語（町に住む人の国籍に合わせて選ぶ）。訳の無い町の「外国の方へ」のページには、10 の言葉で「ブラウザの翻訳を使ってください」と国の外国人生活支援ポータルサイトへのつなぎを出す

## しくみ

```
国の統計で全国 1,741 市区町村を比べる（Claude なし）
  → 町を選んで「調べ始める」（作者の手元の画面）
  → Claude が町の公式サイト・防災計画を探して読み、物差しの問いに出典つきで答える
  → 確かめ役の Claude が資料と照らし、採点役の Claude が 0〜3 点を付け、足りなければ1回探し直す
  → 国や公の機関のデータを重ねる（浸水 × 250m 四方の人口・揺れ・坂・事故・買い物・バス・気候・碑）
  → Claude が「届きにくい人」を見立て、その人の支援の問いを結ぶ。町・字ごとのひとこと、いま、できること
  → 権利・食い違い・古いデータ・避難にひびくものだけ人が確かめる（確かめる一覧）
  → 作者の決め方がいつも同じだった種類は AI が決め、作者が確かめるたびに「次からの決まり」を学ぶ（判断と、答えの書き方に使う）
  → 公開のページは静的なファイルだけで動く（Claude も鍵も使わない）
  → 見張り：出典のページを取り直し、消えた・中身が変わったものだけ Claude が答えと照らし直す（作りっぱなしにしない）
```

AI が作った文は、どれも「渡した数と、確かめ済みの答えだけ」を使わせ、文の中の数と引用を PC で照らしてから出す。

## Claude の使い分け

作品の中（調べる・確かめる。`scripts/`）

| 役 | モデル | 使い方 |
|---|---|---|
| 調べる | Sonnet 5.5 | web_search・web_fetch で町の公式サイトだけを読む（`scripts/research.mjs`） |
| 防災計画の抜き出し | Sonnet 5.5 | PDF のページを文書として渡し、citations で引用つきに（`scripts/plan-excerpts.mjs`） |
| PDF を絵として読む | Opus 5.5 | 文字の取れない防災マップなど（`scripts/try-pdf.mjs`） |
| 確かめ役・採点役・訳し戻し・見張りの照らし直し | Haiku 5.5 | 答えと資料を照らす、0〜3 点、訳を日本語に戻して意味を比べる（語順だけの軽いずれは、数が残っていれば自動で通す）、変わった出典のページと答えを照らす（`scripts/watch-recheck.mjs`） |
| 見立て・ひとこと・いま、できること・クイズ | Sonnet 5.5 | 渡した数だけで書かせ、数と引用を PC で照らす（`scripts/mitate.mjs` ほか） |
| 調べ終わりの提案（物差しに無い問い・調べ方のスキル） | Managed Agents（Sonnet 5.5） | outcomes：物差し（ルーブリック）に合うまで別の採点役がやり直させる（`scripts/managed-propose.mjs`） |
| 確かめ待ちを決める（AI に任せる） | Sonnet 5.5 | 作者の決め方がいつも同じだった種類だけ。PC がいま取り直した出典のページと照らし、OK・直して・人へ。避難・食い違い・古いデータ・権利は人のまま。作者が決め直した種類は人に戻す（`scripts/ai-judge.mjs`） |
| 確かめたものから学ぶ | Sonnet 5.5 | 作者が確かめるたびに「次からの決まり」を 1 つ書き、AI の判断と、調べる役の答えの書き方に渡す。作者は一覧で止められる（`scripts/lessons.mjs`） |

作る側（Claude Code。この作品はすべて Claude Code で作った）

- スキル：町を深く調べる手順（`.claude/skills/town-deepen`）、外部のデータを重ねる手順（`.claude/skills/add-open-data`）
- フック：コミットの前に、鍵の文字列・`local/` のもの・PC の道筋が入っていないかを止める（`.claude/settings.json` → `scripts/hooks/check-commit.mjs`）
- サブエージェント：準備の決めごととの突き合わせ、抜けの洗い出し、デモの台本と作品の照らし合わせ（数・言葉・場面を1つずつ。食い違い22件）
- ブラウザ（MCP）：町のページ・調べる画面・スマホの幅を実際に開いて確かめる
- 実機：USB でつないだ Android のスマホで手元のサーバーを開き、画面を撮って確かめる（地図のボタンの重なりなど）
- 別のセッション：台本と概要の文書（作品の外）を受け持つセッションに、数の直しを知らせる
- 動画づくり：スマホの画面は adb で録り、書き出した動画を数秒ごとに止めて見て直す所を挙げた。Premiere Pro に読み込める「つないだ状態」のファイル（Final Cut Pro XML）と字幕の絵を作り、作者が仕上げた（動画と音のファイルはリポジトリに入れない）

## 安心して使えるための決まり

- 出典は公式（と国・公の機関）だけ。どの数字にも出典と時点を添える。想定・確率は「めやす」と書き、断定しない。住む人のページで全国と比べるときは、全国の真ん中の値を添える（上か下の10番目までは「○番目」、ほかは「高いほう」「低いほう」）
- 医療の助言はしない。転載を禁じているサイトは、事実とリンクだけにする
- 取得は robots.txt と利用規約に従い、名乗って、同じサイトへは1秒以上あける。取ったものそのものは `local/` にだけ置く
- 人が確かめたもの・自動で出したものの記録（承認の台帳）を残し、サイトごとに取り消せる
- 出典のページが消えていたら（404）、検索に残った古い内容のことがあるので、いま開けるページで1回だけ自動で探し直す
- 費用の上限：1回の調べ $4（作者が `.env` の RUN_LIMIT_USD で変えられる。阿賀町の撮影の日は $8、11/6 から $30。調べの途中の町の残りを1回で回すため）・1日 $80・合計 $550（`src/cost.mjs`）
- 住む人のページには、作る側の中身（Claude への問い・費用・台帳の番号）を出さない。AI が作ったものは「AI」と書く
- 古い端末でも動く：iOS 15.4 以降の Safari で動く書き方だけを使う（iOS 15 までしか上げられない iPhone 6s・7 でも町のページが開けるように。実機では確かめていない）。細いスマホ（幅 320px）・暗い表示・やさしい日本語のふりがなでも、はみ出さず読める明るさの差にする
- 点検：前に起きた不具合が戻っていないか・作り直し忘れが無いかを、`npm run check`（AI を使わない）と手元の画面の点検（`/check`）で調べてからコミットする。不具合を直したら、点検の例に1行足す

## 動かし方（手元）

```bash
npm install
npm run serve            # 見るだけ。http://127.0.0.1:8080/ （手元だけで待ち受ける）
npm run serve:research   # 調べる・確かめる画面も使う（.env の ANTHROPIC_API_KEY を読む）
npm run check            # 点検（AI を使わない・数十秒）。画面の点検は http://127.0.0.1:8080/check
```

API の鍵は、このフォルダの `.env`（`.gitignore` 済み）にだけ置く。町のサイトなどを取るときの名札（User-Agent）は、作者の名札（`machi-shirube/0.1 (+https://github.com/tyra0119/machi-shirube)`）になっている。自分で動かすときは、`.env` に `MACHI_SHIRUBE_UA=自分のアプリの名前/版 (+自分の連絡先の URL)` を書いて、自分の名札に変える（相手のサイトから、取りに来たのが誰か分かるように。`src/ua.mjs`）。公開のサイト（GitHub Pages）は `site/` をそのまま配る（`.github/workflows/pages.yml`）。

デモ動画を録るためのページ（ふだんの画面には出ない）：
- `flyover.html`：これからの姿の演出（イメージ）。夜の日本の上を沖縄から札幌へ立体で飛び、町が灯っていく。画面にいつも「演出（イメージ）」と出す。地形は地理院の標高タイル、町の形は国土数値情報 N03
- デモ動画の冒頭（演出の飛行）の曲：「Frame-Dragging」The Grey Room / Density & Time（YouTube オーディオ ライブラリ。収益化する動画も含めあらゆる動画で使え、帰属表示は不要。曲のファイルはこのリポジトリに入れない〈単体での配布は許されていない〉）
- `scenes.html?scene=…`：動画の「動き」の場面（防災計画 454 ページ → 1枚・5,340 人・52.1% → 86.1%・物差しのます目・資料の1行がカードに・終わりの札）。数と文は作品の本物のデータから読み、画面の隅に「演出（イメージ）」と出す
- `index.html?wave`：本物の灯りの波。全国 1,741 の市区町村（どれも国の統計で特色のカードがある）を九州から北へ順に灯し、灯りきった日本の上に、Claude が深く調べた町を光らせる。`?wave&clean` で、メニューや地図のボタンを隠して地図だけに

町を1つ深く調べる順番は `.claude/skills/town-deepen/SKILL.md` に書いている（国のデータを重ねる → 調べる → 見立て → ひとこと → いま、できること → 訳）。

## データの作り方

期間前に取った公開データ（`docs/sources.md`）を `data/raw/` に置いてから：

```bash
npm run build:japan-map  # 市区町村の形（N03）→ site/data/japan.topo.json ほか
npm run build:census     # 国勢調査2020 の世帯と住まい（e-Stat から47都道府県ぶん取る）→ data/census-munis.json
npm run build:stats      # 住民基本台帳と国勢調査から、全国の市区町村 1,741 と比べた数字 → site/data/stats.json
npm run build:flags      # 南海トラフの津波・火山・豪雪・離島の印 → site/data/flags.json
npm run build:towns -- all  # 全国の町・字の形と数字（e-Stat から県ごとに取る）→ site/data/towns/
npm run build:lore       # 昔の災害を伝える碑（国土地理院）→ site/data/lore/
```

町ごとに国のデータを重ねる計算は `node scripts/overlays.mjs <市区町村コード>`（町を調べるときにも自動で動く）。
e-Stat などから取るときは名乗り、1秒以上あけ、手元にあるものは取り直さない。
