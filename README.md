# まちしるべ

町を選ぶと、その町で暮らしの情報が届きにくい人を Claude が見つけ、
その人に届くページを出典つきで作る仕組み。

- Built with Claude: Japan 2026 の作品（テーマ2「本来、誰にでも届くべきものを」）
- 作者: tyra
- 公開サイト: https://tyra0119.github.io/machi-shirube/ （準備中）

## 何をするもの

1. 全国1,741市区町村を国の統計で比べ、「この町で情報が届きにくいのは誰か」を見つける
2. Claude が町のサイト・防災計画などを探して読み、出典つきで答える
3. 町ごとの深掘り（浸水と人口の重なり・坂・避難場所までの時間、出典つきの町の話題）を作る
4. 権利・食い違い・古いデータ・気をつけたい話題だけ人が確かめ、ほかは自動で承認する
5. 公開されたページは Claude なしで動く（見るだけ）

## 作りの決まり

- 調査は作者の PC で動かし、承認されたものだけを公開する。
  公開のページは静的なファイルだけで、API の鍵は含まない
- 出典は公式のみ。どの数字にも出典と時点を添える。想定・確率は「めやす」で、断定しない
- 医療の助言はしない。転載を禁じているサイトは、事実とリンクだけにする
- 取得は robots.txt と利用規約に従い、名乗って、同じサイトへは1秒以上あける
